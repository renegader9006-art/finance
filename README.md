# Баланс

Мобильное приложение для учета доходов, расходов, долгов и накоплений.

## Возможности

- отдельные данные для каждого вошедшего пользователя;
- добавление и удаление операций;
- переключение месяцев, поиск и фильтры;
- автоматический баланс и график движения средств;
- месячные лимиты по категориям;
- цель накоплений;
- экспорт текущего месяца в CSV;
- интерфейс, оптимизированный для телефона.

## Запуск

Требуется Node.js 22 или новее.

```bash
npm ci
npm run dev
```

## Размещение

GitHub можно использовать как репозиторий исходного кода. GitHub Pages не запускает серверную часть, поэтому для регистрации и постоянного хранения данных нужен хостинг с поддержкой Cloudflare Workers и D1 либо отдельный внешний сервис авторизации и базы данных.

Для полной версии предусмотрены защищенный вход, база D1 с миграциями в `drizzle/` и серверные маршруты в `app/api/ledger/`.
